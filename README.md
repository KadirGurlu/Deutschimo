# Deutschimo Platform

Deutschimo için hazırlanmış çok sayfalı, responsive Next.js + TypeScript prototipi.

## Kapsam

- Ana sayfa
- Kurs kataloğu
- Kurs detay sayfası
- Giriş sayfası
- Onboarding
- Kullanıcı dashboard'u
- Ders çalışma ekranı
- Quiz ekranı
- İlerleme analizi
- Kelime flashcard ekranı
- Yazma alıştırması
- Sınav hazırlık paneli
- Profil ve ayarlar
- Admin dashboard
- Kurs içerik yönetimi

## Teknoloji

- Next.js App Router
- React + TypeScript
- Recharts
- Lucide Icons
- Merkezi CSS tasarım tokenları
- Mock veri ve servis katmanı

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda `http://localhost:3000` adresini açın.

## Önemli not

Bu paket yatırımcı/ürün demosu düzeyinde frontend prototipidir. Kimlik doğrulama, PostgreSQL/Prisma, dosya yükleme, ödeme ve gerçek öğrenme analitiği için backend entegrasyonu sonraki aşamada yapılmalıdır.
