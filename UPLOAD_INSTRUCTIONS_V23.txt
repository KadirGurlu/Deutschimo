DEUTSCHIMO V23 YÜKLEME TALİMATI
================================

1. deutschimo-v23-guncelleme-paketi.zip dosyasını çıkartın.
2. GitHub Desktop uygulamasında Deutschimo repository'sini seçin.
3. Repository > Show in Explorer seçeneğine basın.
4. Güncelleme paketindeki klasör ve dosyaları açılan Deutschimo ana klasörünün üzerine kopyalayın.
5. Windows sorarsa "Hedefteki dosyaları değiştir" seçeneğini kullanın.
6. GitHub Desktop'a dönün.
7. Summary alanına şunu yazın:

   Add Deutschimo V23 personalized smart review

8. Commit to main butonuna basın.
9. Push origin butonuna basın.
10. Vercel'de yeni deployment'ın Ready olmasını bekleyin.

KONTROL EDİLECEKLER
-------------------

- Sol menüde Dashboard yerine Öğrenci Paneli yazmalı.
- Kurslarım, Zayıf Konular, Yetkinlik Haritası, Hata Geçmişi ve Sınavlar görünmemeli.
- Akıllı Tekrar ekranında kişisel kaynak özeti görünmeli.
- Öğrencinin açık hata kayıtları ve zayıf konuları tekrar sırasına yansımalı.
- Eski /weak-topics, /competency ve /mistakes bağlantıları /smart-review sayfasına yönlenmeli.
