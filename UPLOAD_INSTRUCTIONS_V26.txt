DEUTSCHIMO V26 YÜKLEME TALİMATI

1. deutschimo-v26-guncelleme-paketi.zip dosyasını çıkart.
2. GitHub Desktop içinde Deutschimo deposunu seç.
3. Repository > Show in Explorer menüsüne bas.
4. Güncelleme paketindeki dosyaları açılan Deutschimo klasörünün üzerine kopyala.
5. Windows sorarsa "Hedefteki dosyaları değiştir" seçeneğini kullan.
6. GitHub Desktop'a dön.
7. Summary alanına şunu yaz:
   Add Deutschimo V26 courses and header improvements
8. Commit to main butonuna bas.
9. Push origin butonuna bas.
10. Vercel deployment durumunun Ready olmasını bekle.

KONTROL LİSTESİ
- Sol menüde Kurslar görünmeli.
- Kurslar sayfasında A1, A2, B1 ve B2 kartları açılmalı.
- Kurs kartına basınca üniteler ve kurs içeriği görünmeli.
- Deutschimo logosu sol kenarda, kullanıcı adı ve çıkış sağ kenarda olmalı.
- İlerleme kaydedildi etiketi görünmemeli.
- Çıkış butonu onay sorusu göstermeli.

V26 veritabanı şemasını değiştirmez. db push veya seed çalıştırma.
