DEUTSCHIMO V27 YÜKLEME TALİMATI
================================

V27 veritabanı şemasını değiştirmez. Kullanıcılar ve ilerleme kayıtları korunur.

1. `deutschimo-v27-guncelleme-paketi.zip` dosyasını çıkart.
2. GitHub Desktop'ta Deutschimo deposunu seç.
3. Repository > Show in Explorer seçeneğine bas.
4. Güncelleme paketindeki dosya ve klasörleri açılan Deutschimo klasörünün üzerine kopyala.
5. Windows sorarsa "Hedefteki dosyaları değiştir" seçeneğini kullan.
6. GitHub Desktop'a dön.
7. Summary alanına şunu yaz:

   Add Deutschimo V27 content quality assurance

8. Commit to main butonuna bas.
9. Push origin butonuna bas.
10. Vercel'de yeni deployment'ın Ready olmasını bekle.

KONTROL
-------

Deployment sonrasında:

- A1-A2-B1-B2 kurslarından örnek üniteleri aç.
- Admin > İçerik Yönetimi sayfasında V27 kalite kartını kontrol et.
- A1 ünitelerinde "Yayına hazır" durumunu görmelisin.
- A2-B1-B2 ünitelerinde "Editör kontrolünde" durumu görünmelidir.

İsteğe bağlı yerel doğrulama:

   npm install
   npm run validate:v27
   npm run validate:content
   npm run build

Yeni Environment Variable, `prisma db push` veya seed işlemi gerekmez.
