ÖNEMLİ
------
- Bu paket V28.4 dosyalarını kümülatif olarak içerir.

1. OPENAI API HAZIRLIĞI
-----------------------
Yazma Koçu gerçek AI değerlendirmesi için OpenAI API kullanır.
ChatGPT Plus aboneliği API kullanımını içermez; API Platform hesabı ve ayrı kullanım bakiyesi gerekir.

OpenAI API Platform'da:
- Bir API anahtarı oluştur.
- API billing/spend limitlerini kendi bütçene göre ayarla.
- Anahtarı GitHub'a veya ekran görüntüsüne koyma.

2. VERCEL ENVIRONMENT VARIABLES
-------------------------------
Vercel -> Deutschimo -> Environment Variables -> Add Environment Variable.

Preview için:
Key: OPENAI_API_KEY
Value: kendi API anahtarın
Environment: Preview
Sensitive: Açık

Preview için ikinci değişken:
Key: OPENAI_WRITING_MODEL
Value: gpt-5.4-mini
Environment: Preview
Sensitive: Kapalı olabilir

Preview testleri başarılı olduktan sonra aynı iki değişkeni Production kapsamına da ekle.
API anahtarında NEXT_PUBLIC_ öneki kullanma.
